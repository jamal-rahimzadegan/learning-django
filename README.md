# Learning Django

A hands-on repository documenting personal learning, core concepts, and practical examples built with the Django web framework and React-JS.

## Overview

This project serves as a step-by-step exploration of Django fundamentals, including:
- Django project and application architecture
- URL routing, views, and templates
- Models, migrations, and database operations (ORM)
- Django admin interface customization
- Forms and basic user handling

## Prerequisites

- Python 3.4+
- `pip` and `virtualenv`
